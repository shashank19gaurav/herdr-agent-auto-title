# v0.2.0 — Multi-harness titles and pi auto-naming

## What's new

- Renamed the project/repository to **Herdr Agent Auto-Title** / `herdr-agent-auto-title`.
- Added static Copilot/pi adapters with shared title stability, session quarantine,
  split-pane ownership, machine isolation, and pre-rename identity checks.
- Added stock pi native session-title synchronization without a pi extension.
- Added optional, separately installed **Pi Auto-Name** in `extensions/pi-auto-name/`.
  It uses the chat's selected model/provider by default, performs one bounded
  background naming attempt, preserves existing names, and sets pi's native name.
- Added a harness contribution guide, fixtures, regression tests, and host checks.

## Install and upgrade

```powershell
# For an existing installation, first stop the old watcher:
herdr plugin disable copilot-auto-title
# Wait for the watcher to exit, or close only its watcher pane.
herdr plugin install shashank19gaurav/herdr-agent-auto-title --ref v0.2.0
herdr plugin enable copilot-auto-title
herdr plugin action invoke copilot-auto-title.start
```

For a fresh installation, start at `plugin install`. Review the installation
prompt. The installed plugin ID/action prefix remains `copilot-auto-title`, and
the singleton namespace is retained to prevent old/new watchers racing.
Historical tags remain available. Explicitly use the new repository source on
upgrade instead of relying on old pinned source URLs or redirects.

The optional pi package is **not installed by the Herdr plugin**. See
[Pi Auto-Name installation, cost, and privacy](../../extensions/pi-auto-name/README.md).
Naming adds a model request and normal provider usage/cost. Direct extension
requests are not included in this implementation's pi chat usage totals.

Existing local checkout links need not move after the GitHub rename. Moving a
linked checkout requires updating both Herdr and pi package references.

- Installed pi 1.3.0 loader/runner/session host checks passed on Node 22/24 with
  mocked model responses; independent extension review repeated these checks.

- The local checkout watcher and optional extension were activated in the user's
  environment; the user confirmed automatic naming works.

## Known limitations and remaining live checks

- Live mixed Copilot/pi split testing, full remote session transitions,
  reconnect disruption, and fresh/pinned-install upgrade lifecycle testing
  remain incomplete. Offline tests cover mixed ownership and lifecycle behavior.
- Live smoke tests initially exercised scoped checkout code, not a packaged
  GitHub installation. Local activation is not proof of all GitHub upgrade paths.
- Pi without session IDs has the documented title/session atomicity limitation.
- Auto-naming targets interactive TUI mode; manual Herdr labels are overwritten
  by the watcher, so use pi `/name` for a lasting custom name.
- Input cancellation starts when pi dispatches input to this extension; an earlier
  extension handler may delay or short-circuit that dispatch.
- Sensitive-text filtering is best effort, not a security boundary. Provider
  billing, title quality, and cancellation enforcement vary by provider.
- No npm package is published for the optional extension in this release.
